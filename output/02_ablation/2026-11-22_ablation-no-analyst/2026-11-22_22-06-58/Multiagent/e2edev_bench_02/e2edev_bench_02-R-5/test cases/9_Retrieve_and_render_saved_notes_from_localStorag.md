# Retrieve and render saved notes from localStorage with content

Case ID · G-009

Requirements · e2edev\_bench\_02-R-5

Verify that when the webpage loads with stored notes containing content, the app dynamically creates a div with the class note containing a tools div with edit and delete buttons, a main div (data-testid="note-main") showing the note content, and a textarea (data-testid="note-textarea") which is hidden by default.
