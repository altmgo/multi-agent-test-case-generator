# Toggle Text Box Visibility via Toggle Button

Case ID · G-001

Requirements · e2edev\_bench\_04-R-1

Verify that clicking the 'Toggle Text Box' button (data-testid="toggle-button") changes the visibility of the text box (data-testid="text-box") by adding or removing the 'show' class according to the user interaction, starting from an initially hidden state and reflecting the final state correctly.
