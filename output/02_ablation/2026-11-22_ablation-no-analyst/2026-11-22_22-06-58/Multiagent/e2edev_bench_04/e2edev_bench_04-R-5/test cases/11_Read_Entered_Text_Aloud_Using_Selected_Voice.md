# Read Entered Text Aloud Using Selected Voice

Case ID · G-011

Requirements · e2edev\_bench\_04-R-5

Verify that when the user toggles the text box via the 'Toggle Text Box' button (data-testid='toggle-button'), enters text into the textarea (data-testid='text-area'), selects a voice from the dropdown (data-testid='voice-select'), and clicks the 'Read Text' button (data-testid='read-button'), the system uses the selected voice to read the entered text aloud.
