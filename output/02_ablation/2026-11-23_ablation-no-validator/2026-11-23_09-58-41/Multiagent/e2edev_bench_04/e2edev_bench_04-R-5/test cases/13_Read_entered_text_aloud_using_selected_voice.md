# Read entered text aloud using selected voice

Case ID · G-013

Requirements · e2edev\_bench\_04-R-5

Verify that when the user enters text into the textarea (data-testid='text-area'), toggles the text box (data-testid='text-box') via the 'Toggle Text Box' button (data-testid='toggle-button'), and clicks the 'Read Text' button (data-testid='read-button'), the system uses the selected voice from the dropdown (data-testid='voice-select') to read the entered text aloud.
