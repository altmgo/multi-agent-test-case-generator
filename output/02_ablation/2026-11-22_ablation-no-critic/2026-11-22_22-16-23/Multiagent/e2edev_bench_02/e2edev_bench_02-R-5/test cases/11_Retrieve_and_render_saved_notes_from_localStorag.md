# Retrieve and render saved notes from localStorage on page load

Case ID · G-011

Requirements · e2edev\_bench\_02-R-5

Verify that when the Notes App webpage loads, it retrieves saved notes from localStorage and dynamically creates a div element with the class note including tools with Edit and Delete buttons, a main div (data-testid="note-main"), and a textarea (data-testid="note-textarea"), with the content displayed in the main div and the textarea hidden by default for notes with content.
