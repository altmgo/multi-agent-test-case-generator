# Populate Voice Dropdown on Text Box Open

Case ID · G-007

Requirements · e2edev\_bench\_04-R-3

Verify that when the user opens the text box using the 'Toggle Text Box' button (data-testid='toggle-button'), the system invokes getVoices via speechSynthesis.getVoices() and populates the 'Choose Voice' dropdown (data-testid='voice-select') with option elements showing voice names and languages.
