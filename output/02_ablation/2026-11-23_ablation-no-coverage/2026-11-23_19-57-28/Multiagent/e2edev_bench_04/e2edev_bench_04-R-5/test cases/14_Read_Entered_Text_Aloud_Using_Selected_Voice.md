# Read Entered Text Aloud Using Selected Voice

Case ID · G-014

Requirements · e2edev\_bench\_04-R-5

Verify that when the user toggles the text box open via the toggle button, enters text into the textarea (data-testid='text-area'), selects a voice from the dropdown (data-testid='voice-select'), and clicks the 'Read Text' button (data-testid='read-button'), the system uses the selected voice to read the entered text aloud.
