# Read entered text aloud using selected voice and text box controls

Case ID · G-014

Requirements · e2edev\_bench\_04-R-5

Verify that when the user enters text into the textarea (data-testid='text-area'), toggles the text box (data-testid='text-box') via the 'Toggle Text Box' button (data-testid='toggle-button'), selects a voice from the dropdown (data-testid='voice-select'), and clicks the 'Read Text' button (data-testid='read-button'), the system uses the selected voice to read the entered text aloud.
