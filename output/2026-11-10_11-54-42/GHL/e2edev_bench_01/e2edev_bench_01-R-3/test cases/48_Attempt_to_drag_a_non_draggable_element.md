# Attempt to drag a non‑draggable element

Case ID · G-048

Requirements · e2edev\_bench\_01-R-1, e2edev\_bench\_01-R-3

User tries to drag an element that lacks the draggable attribute (e.g., a header or static text). No drag event should be initiated, and dropping the element into the drop area must not modify the cart or total. The system should remain stable with no errors.
