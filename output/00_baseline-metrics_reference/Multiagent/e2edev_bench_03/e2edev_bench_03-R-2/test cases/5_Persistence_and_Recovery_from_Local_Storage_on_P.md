# Persistence and Recovery from Local Storage on Page Load

Case ID · G-005

Requirements · e2edev\_bench\_03-R-2, e2edev\_bench\_03-R-3

Verify that upon loading the webpage, the system retrieves 'selectedSeats' and 'selectedMovieIndex' from localStorage, correctly restores the selected class on corresponding seats, sets the movie dropdown value, and defaults safely if localStorage is empty.
