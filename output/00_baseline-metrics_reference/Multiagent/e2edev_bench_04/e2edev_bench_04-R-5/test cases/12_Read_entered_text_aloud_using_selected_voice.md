# Read entered text aloud using selected voice

Case ID · G-012

Requirements · e2edev\_bench\_04-R-5

Verify that when the user toggles the text box open, enters text into the textarea (data-testid='text-area'), selects a voice, and clicks the 'Read Text' button (data-testid='read-button'), the system correctly triggers speech synthesis using the entered text and selected voice.
