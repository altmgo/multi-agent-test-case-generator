# Normal State Transition - Drag Product and Drop into Cart

Case ID · G-004

Requirements · e2edev\_bench\_01-R-1, e2edev\_bench\_01-R-3, e2edev\_bench\_01-R-5

Transition from Idle state to Dragging state when user drags a product item with draggable='true', and then to Cart Updated state when dropped into the drop area (id='div1'). Verifies that product title, unit price, quantity, and total price update correctly.
