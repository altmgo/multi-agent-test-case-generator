# Successful Drag Event Initiation for Product Item

Case ID · G-037

Requirements · e2edev\_bench\_01-R-1

Verify that when a user drags a product item (li element with draggable='true' and data-testid='product-item-1') from the product list, the system initiates a drag event and successfully captures the product's title (from data-testid='product-title-1') and price (from data-testid='product-price-1') for transfer.
