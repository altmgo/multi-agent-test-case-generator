# Successful Drag and Drop of Repeated Products to Cart

Case ID · G-040

Requirements · e2edev\_bench\_01-R-1, e2edev\_bench\_01-R-3, e2edev\_bench\_01-R-5

Verify that a user can drag and drop the same product item multiple times into the drop area, and the system supports adding repeated products by incrementing the quantity in .box1 and updating totals accordingly.
