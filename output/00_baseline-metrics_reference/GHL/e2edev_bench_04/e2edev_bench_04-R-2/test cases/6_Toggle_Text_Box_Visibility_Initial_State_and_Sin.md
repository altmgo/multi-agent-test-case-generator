# Toggle Text Box Visibility Initial State and Single Click

Case ID · G-006

Requirements · e2edev\_bench\_04-R-1, e2edev\_bench\_04-R-2

Verify that the text box (data-testid='text-box') is initially hidden without the 'show' class, and becomes visible with the 'show' class exactly once after clicking the 'Toggle Text Box' button (data-testid='toggle-button') at the lower boundary of interactions.
