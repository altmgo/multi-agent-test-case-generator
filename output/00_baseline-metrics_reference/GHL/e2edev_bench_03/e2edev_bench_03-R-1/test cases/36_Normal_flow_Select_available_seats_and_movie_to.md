# Normal flow: Select available seats and movie to calculate total price

Case ID · G-036

Requirements · e2edev\_bench\_03-R-1

User loads the webpage, selects multiple available seats, and chooses a movie from the dropdown (data-testid="movie-select"). Verifies that the selected seat count updates in data-testid="selected-count" and the total price correctly calculates as selected seats multiplied by the movie price in data-testid="total-price".
