# Abnormal Flow: Attempting to Select Occupied Seats and Deselecting Seats

Case ID · G-014

Requirements · e2edev\_bench\_03-R-1, e2edev\_bench\_03-R-2, e2edev\_bench\_03-R-4, e2edev\_bench\_03-R-5

User interacts with the seat map, attempts to click on an occupied seat to verify it cannot be selected and does not affect the count or price, and then deselects a previously selected seat to ensure the count and price decrease correctly.
