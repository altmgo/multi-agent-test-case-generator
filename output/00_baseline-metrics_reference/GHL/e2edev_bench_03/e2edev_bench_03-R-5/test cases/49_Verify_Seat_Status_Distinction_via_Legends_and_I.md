# Verify Seat Status Distinction via Legends and Interactive Seating Workflow

Case ID · G-049

Requirements · e2edev\_bench\_03-R-5

Verify that users can distinguish between available, selected, and occupied seats using status legends (such as data-testid = 'seat-select'), ensure occupied seats are non-interactive and unselectable, verify available seats toggle selection upon click, and confirm that selected seat counts and total prices update correctly.
