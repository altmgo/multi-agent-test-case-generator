# Toggle Text Box Visibility

Case ID · G-001

Requirements · e2edev\_bench\_04-R-1

Preconditions: The Speech Text Reader is loaded and the text box (data-testid='text-box') is initially hidden. Steps: Click the toggle button (data-testid='toggle-button'). Expected Behavior: The text box appears by adding the 'show' class. Click the toggle button again to hide it and verify the 'show' class is removed.
