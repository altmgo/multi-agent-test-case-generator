# Select Voice from Dropdown

Case ID · G-004

Requirements · e2edev\_bench\_04-R-4

Preconditions: The text box is open and the voice dropdown is populated. Steps: Select a specific voice option (e.g., containing 'US' or 'CN') from the 'Choose Voice' dropdown (data-testid='voice-select').
