# Interact with Predefined Phrase Box

Case ID · G-006

Requirements · e2edev\_bench\_04-R-6

Preconditions: The application is loaded with dynamically generated predefined phrase boxes containing an image and paragraph. Steps: Click on a phrase box. Expected Behavior: The system reads the associated text aloud via the Web Speech API and visually highlights the box with the active class for 800 milliseconds.
