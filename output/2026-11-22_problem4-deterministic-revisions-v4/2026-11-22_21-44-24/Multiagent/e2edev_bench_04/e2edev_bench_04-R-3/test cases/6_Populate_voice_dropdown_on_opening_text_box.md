# Populate voice dropdown on opening text box

Case ID · G-006

Requirements · e2edev\_bench\_04-R-3

Verify that after the user opens the text box using the 'Toggle Text Box' button (data-testid='toggle-button'), the system populates the 'Choose Voice' dropdown (data-testid='voice-select') with available voices retrieved via speechSynthesis.getVoices(), setting option values to voice names and display texts to voice names and languages.
