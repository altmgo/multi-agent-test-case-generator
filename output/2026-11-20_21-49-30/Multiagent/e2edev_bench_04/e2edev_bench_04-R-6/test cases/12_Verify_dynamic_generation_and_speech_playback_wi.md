Case ID · G-012

Requirements · e2edev\_bench\_04-R-6

Verify that the system dynamically generates predefined phrase boxes in the main section based on a data array containing images and paragraphs, and when a user clicks on a box, it reads the associated text aloud using the Web Speech API and visually highlights the box by adding the active class for 800 milliseconds.
