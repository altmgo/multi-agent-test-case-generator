# Add single note via Add note button

Case ID · G-001

Requirements · e2edev\_bench\_02-R-1

Clicking the "Add note" button (id="add", class="add", data-testid="add-note-button") creates a new note appended to the document body as a <div> element with the class "note", containing a visible, empty <textarea> (data-testid="note-textarea") for user input.
