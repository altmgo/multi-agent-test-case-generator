# Populate Voice Dropdown on Text Box Open

Case ID · G-006

Requirements · e2edev\_bench\_04-R-3

Verify that when the user opens the text box using the 'Toggle Text Box' button (data-testid='toggle-button'), the system invokes getVoices using speechSynthesis.getVoices() and populates the 'Choose Voice' dropdown (data-testid='voice-select') with option elements whose values are set to voice names and display texts show voice names and languages.
