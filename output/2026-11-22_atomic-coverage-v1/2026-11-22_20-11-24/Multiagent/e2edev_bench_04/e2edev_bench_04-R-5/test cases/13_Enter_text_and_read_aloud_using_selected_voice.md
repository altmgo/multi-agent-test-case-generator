Case ID · G-013

Requirements · e2edev\_bench\_04-R-5

Verify that the user can enter text into the textarea (data-testid='text-area'), select a voice from the dropdown (data-testid='voice-select'), toggle the text box (data-testid='text-box') via the 'Toggle Text Box' button (data-testid='toggle-button'), and click the 'Read Text' button (data-testid='read-button') to read the entered text aloud using the selected voice.
