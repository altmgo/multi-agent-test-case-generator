# e2edev\_bench\_03-R-1

Upon loading the webpage, users can interact with the seat map and movie dropdown to dynamically update the total price. Clicking on any available seat (i.e., a seat without the occupied class) marks it as selected, and the selected seat count updates in the element with data-testid="selected-count". Users can also select a movie from the dropdown (data-testid="movie-select"), where each option has a value representing the ticket price. The total price, shown in the element with data-testid="total-price", is calculated as the number of selected seats multiplied by the selected movie’s price. Seats marked as occupied must not be selectable and should not affect the count or price. Changing the selected movie at any time updates the total price accordingly.
