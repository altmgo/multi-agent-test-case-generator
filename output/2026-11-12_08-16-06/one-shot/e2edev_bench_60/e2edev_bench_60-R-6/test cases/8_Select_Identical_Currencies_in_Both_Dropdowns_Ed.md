# Select Identical Currencies in Both Dropdowns \(Edge Case\)

Case ID · G-008

Requirements · e2edev\_bench\_60-R-6

Verify that when both 'currency-one' and 'currency-two' are selected to be the same currency, the system handles the edge case by displaying '1 [currency-one] = 1 [currency-two]' in the exchange rate element.
