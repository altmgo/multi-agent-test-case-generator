# Dynamic Tag Generation and Display

Case ID · G-002

Requirements · e2edev\_bench\_66-R-1, e2edev\_bench\_66-R-2, e2edev\_bench\_66-R-3

Verify that typing choices separated by commas into the textarea dynamically parses and displays them as individual tags in the container with data-testid='tags-container', each with a unique 'data-id' attribute formatted as 'tag-{index}'.
