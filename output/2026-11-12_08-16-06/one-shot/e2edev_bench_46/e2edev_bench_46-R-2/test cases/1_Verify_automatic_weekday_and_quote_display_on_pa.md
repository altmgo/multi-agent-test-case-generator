# Verify automatic weekday and quote display on page load

Case ID · G-001

Requirements · e2edev\_bench\_46-R-1, e2edev\_bench\_46-R-2

Verify that upon loading the web page, the application correctly determines the current day of the week using local date settings and displays the correct weekday name in the span with data-testid='weekday' and the corresponding quote in the span with data-testid='phrase' without any user interaction.
