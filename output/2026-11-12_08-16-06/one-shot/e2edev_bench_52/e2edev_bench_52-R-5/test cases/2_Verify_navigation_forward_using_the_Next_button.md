Case ID · G-002

Requirements · e2edev\_bench\_52-R-2, e2edev\_bench\_52-R-4, e2edev\_bench\_52-R-5

Verify that clicking the 'Next' button activates the next progress circle, updates the progress bar width proportionally, disables 'Prev' only if first is active, and disables 'Next' when the last circle is active.
