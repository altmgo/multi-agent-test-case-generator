# e2edev\_bench\_37-R-6

The system must clear the content display area with data-testid 'content-display' each time the button with data-testid 'move-text-button' is clicked. If the text area with data-testid 'text-area' contains text, the content display area should initially be empty before displaying the text. If the text area is empty, an alert with the message '请输入文本信息' should be shown, and the content display area should remain empty.
