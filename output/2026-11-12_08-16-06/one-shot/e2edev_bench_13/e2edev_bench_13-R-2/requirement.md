# e2edev\_bench\_13-R-2

When the user selects an option from the first dropdown (data-testid='first-option-select')—which includes 'Select an Option' (data-testid='first-option-select'), 'Centimeters' (data-testid='first-option-centimeters'), 'Inches' (data-testid='first-option-inches'), 'Meters' (data-testid='first-option-meters'), 'Kilometers' (data-testid='first-option-kilometers'), and 'Miles' (data-testid='first-option-miles'), the system should dynamically update the input field's (data-testid='height-input') placeholder to reflect the selected unit. The placeholder should change to 'Enter [Selected Unit]...' where [Selected Unit] is the unit chosen by the user. Additionally, the height name section (data-testid='height-name') should display '[Selected Unit]:' to indicate the current unit of measurement. If the user selects the default option 'Select an Option', the input field should retain its original placeholder 'Enter Height...', and the height name section should remain empty.
