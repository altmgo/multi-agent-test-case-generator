# e2edev\_bench\_37-R-4

When the button with data-testid 'move-text-button' is clicked, the system should change the button's background color to '#ccc' to indicate activation, provided that the textarea with data-testid 'text-area' is not empty. If the textarea is empty, the button's background color should remain unchanged, and an alert should be displayed with the message '请输入文本信息'.
