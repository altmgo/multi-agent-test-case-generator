# Invalid Interest Rate Input \(Non-numeric or \<= 0\)

Case ID · G-026

Requirements · e2edev\_bench\_24-R-2, e2edev\_bench\_24-R-5, e2edev\_bench\_24-R-6

Enter an invalid value (non-numeric or less than/equal to 0) in the 'Interest Rate (%)' field while other fields are valid. Trigger calculation via button or Enter key. Verify that an alert stating 'Please Enter Valid Values!!' is shown.
