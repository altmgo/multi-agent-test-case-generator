# Validation Failure with Invalid Principal Input

Case ID · G-031

Requirements · e2edev\_bench\_24-R-1, e2edev\_bench\_24-R-5, e2edev\_bench\_24-R-6

User enters an invalid value (e.g., negative, zero, non-numeric, or empty) in the Principal input field and attempts to calculate via button click or Enter key. The system prevents calculation and displays an alert with the message 'Please Enter Valid Values!!'.
