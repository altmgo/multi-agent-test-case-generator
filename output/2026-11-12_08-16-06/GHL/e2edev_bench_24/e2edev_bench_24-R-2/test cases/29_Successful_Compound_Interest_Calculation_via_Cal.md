# Successful Compound Interest Calculation via Calculate Button

Case ID · G-029

Requirements · e2edev\_bench\_24-R-1, e2edev\_bench\_24-R-2, e2edev\_bench\_24-R-3, e2edev\_bench\_24-R-4, e2edev\_bench\_24-R-5

User enters valid positive numeric values into Principal, Interest Rate, Number of Years, and Number of Times in a Single Year fields, then clicks the Calculate button. The system validates all inputs, computes the correct compound interest, rounds it to two decimal places, and displays the output in the result section.
