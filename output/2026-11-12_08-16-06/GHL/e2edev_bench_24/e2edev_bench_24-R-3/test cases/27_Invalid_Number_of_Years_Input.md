# Invalid Number of Years Input

Case ID · G-027

Requirements · e2edev\_bench\_24-R-3, e2edev\_bench\_24-R-5, e2edev\_bench\_24-R-6

Enter an invalid value (empty, negative, or zero) in the 'Number of Years' field with valid entries in other fields. Attempt to calculate. Verify that the alert 'Please Enter Valid Values!!' is displayed.
