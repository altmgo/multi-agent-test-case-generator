# Validation Failure with Invalid Interest Rate Input

Case ID · G-032

Requirements · e2edev\_bench\_24-R-2, e2edev\_bench\_24-R-5, e2edev\_bench\_24-R-6

User enters an invalid value (e.g., negative, zero, or non-numeric) in the Interest Rate field and attempts to calculate. The system prevents calculation, triggers an error alert, and keeps the result section unchanged.
