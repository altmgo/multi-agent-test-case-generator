# Add Task with Whitespace Only

Case ID · G-022

Requirements · e2edev\_bench\_32-R-2, e2edev\_bench\_32-R-3

Attempt to add a task by entering only whitespace characters into the 'task-input' field and pressing 'Enter' or clicking 'add-task-btn'. Verify that no task is added, the input remains empty, and the 'Clear All' button stays hidden.
