# Attempt to add task with empty or whitespace-only description

Case ID · G-002

Requirements · e2edev\_bench\_32-R-2, e2edev\_bench\_32-R-3

Verify that attempting to add a task with an empty string or consisting solely of whitespace into 'task-input' via button click or Enter key does not add any task to the 'task-list' and keeps the 'clear-all-btn' hidden if no tasks exist.
