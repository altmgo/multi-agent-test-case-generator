# Input with Only Commas and Special Characters

Case ID · G-014

Requirements · e2edev\_bench\_66-R-1, e2edev\_bench\_66-R-2, e2edev\_bench\_66-R-3

Test the application behavior when the user enters only commas, whitespace, or special characters into the textarea and presses Enter, ensuring no tags are created, the textarea is cleared, and no random selection occurs.
