# Abnormal Workflow - Invalid input with only commas or empty fields

Case ID · G-013

Requirements · e2edev\_bench\_66-R-2, e2edev\_bench\_66-R-3

Verify that when the user enters only commas, special characters without valid choices, or leaves the textarea empty and presses 'Enter', the tags container remains empty, the textarea is cleared, and no random selection process occurs.
