# Edge Case Workflow - Handle extra spaces, single entries, and trimming

Case ID · G-012

Requirements · e2edev\_bench\_66-R-2, e2edev\_bench\_66-R-3

Verify that input with extra spaces and single entries is correctly processed by trimming leading/trailing spaces, ignoring empty entries, rendering valid span elements with class 'tag' and data-id format 'tag-{index}', and successfully executing the random selection upon pressing 'Enter'.
