# Dynamic State and Label Update on Individual Checkbox Interactions

Case ID · G-024

Requirements · e2edev\_bench\_57-R-1, e2edev\_bench\_57-R-2, e2edev\_bench\_57-R-4

User manually selects all individual checkboxes one by one and verifies that 'checkAll' becomes checked and its label updates to '全不选'. Then, user deselects some checkboxes and verifies that 'checkAll' becomes unchecked while the label displays '全选'. Finally, user deselects all individual checkboxes and verifies the unchecked status and label text.
