# Select All and Deselect All via CheckAll Checkbox

Case ID · G-023

Requirements · e2edev\_bench\_57-R-1, e2edev\_bench\_57-R-2, e2edev\_bench\_57-R-4

User interacts with the 'Select All/None' checkbox ('checkAll') to check all individual checkboxes ('checkbox-1' to 'checkbox-10') and verify that the label ('checkAll-label') updates to '全不选'. Then, user clicks it again to deselect all individual checkboxes and verifies that the label updates to '全选'.
