# State Transition via Reverse Selection Link

Case ID · G-016

Requirements · e2edev\_bench\_57-R-1, e2edev\_bench\_57-R-2, e2edev\_bench\_57-R-3, e2edev\_bench\_57-R-4

Clicking the 'checkReverse' link inverts the state of every individual checkbox, and the system dynamically updates 'checkAll' and its label according to the resulting collective state.
