# Select All when all checkboxes are unchecked

Case ID · G-001

Requirements · e2edev\_bench\_57-R-1, e2edev\_bench\_57-R-2, e2edev\_bench\_57-R-4

Verify that clicking the 'Select All/None' checkbox ('checkAll') when all individual checkboxes ('checkbox-1' to 'checkbox-10') are unchecked selects all individual checkboxes, checks 'checkAll', and updates 'checkAll-label' to '全不选'.
