# Select All when some checkboxes are selected

Case ID · G-003

Requirements · e2edev\_bench\_57-R-1, e2edev\_bench\_57-R-2, e2edev\_bench\_57-R-4

Verify that clicking the 'Select All/None' checkbox ('checkAll') when a mix of individual checkboxes are checked and unchecked selects all individual checkboxes, checks 'checkAll', and updates 'checkAll-label' to '全不选'.
