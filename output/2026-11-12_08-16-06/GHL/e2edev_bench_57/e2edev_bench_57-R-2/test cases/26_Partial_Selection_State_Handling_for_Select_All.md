# Partial Selection State Handling for Select All/None

Case ID · G-026

Requirements · e2edev\_bench\_57-R-1, e2edev\_bench\_57-R-2, e2edev\_bench\_57-R-4

Error guessing test to verify that when some, but not all, individual checkboxes (checkbox-1 to checkbox-10) are selected, the 'Select All/None' checkbox ('checkAll') correctly remains unchecked and its label ('checkAll-label') displays '全选' rather than '全不选'.
