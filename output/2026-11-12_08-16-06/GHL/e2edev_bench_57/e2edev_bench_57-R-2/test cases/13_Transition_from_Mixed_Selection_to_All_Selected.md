# Transition from Mixed Selection to All Selected via Select All/None

Case ID · G-013

Requirements · e2edev\_bench\_57-R-1, e2edev\_bench\_57-R-2, e2edev\_bench\_57-R-4

When some individual checkboxes are selected and some are unselected, clicking the 'checkAll' checkbox selects all individual checkboxes, updates 'checkAll' to checked, and updates 'checkAll-label' to '全不选'.
