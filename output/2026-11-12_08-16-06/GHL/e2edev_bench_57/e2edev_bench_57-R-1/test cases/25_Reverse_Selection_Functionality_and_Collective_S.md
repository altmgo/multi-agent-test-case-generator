# Reverse Selection Functionality and Collective State Update

Case ID · G-025

Requirements · e2edev\_bench\_57-R-1, e2edev\_bench\_57-R-2, e2edev\_bench\_57-R-3, e2edev\_bench\_57-R-4

User starts with a mixed state or any initial state of individual checkboxes ('checkbox-1' to 'checkbox-10') and clicks the 'Reverse Selection' link ('checkReverse'). The system inverts the selection state of each individual checkbox and correctly updates the 'Select All/None' checkbox and its label accordingly.
