# Correct Word Entry Transition

Case ID · G-013

Requirements · e2edev\_bench\_51-R-3, e2edev\_bench\_51-R-4, e2edev\_bench\_51-R-5

Verify that when the user types the correct word matching the target within the time limit, the input field is cleared, the score increments by 1, time increases according to the active difficulty setting, and a new random word is displayed.
