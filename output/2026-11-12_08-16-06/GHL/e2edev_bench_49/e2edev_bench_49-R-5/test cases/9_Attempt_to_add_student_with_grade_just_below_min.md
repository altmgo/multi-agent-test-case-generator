# Attempt to add student with grade just below minimum \(-1\)

Case ID · G-009

Requirements · e2edev\_bench\_49-R-1, e2edev\_bench\_49-R-2, e2edev\_bench\_49-R-5

Enter a valid student name and an invalid grade of -1 (just below the minimum boundary) in the grade input field, then click the 'Add Student' button. Verify that submission is prevented, an error message is displayed, no entry is added to the student list, and the input values are retained.
