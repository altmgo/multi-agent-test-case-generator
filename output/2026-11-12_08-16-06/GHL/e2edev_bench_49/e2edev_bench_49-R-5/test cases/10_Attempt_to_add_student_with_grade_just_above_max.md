# Attempt to add student with grade just above maximum \(101\)

Case ID · G-010

Requirements · e2edev\_bench\_49-R-1, e2edev\_bench\_49-R-2, e2edev\_bench\_49-R-5

Enter a valid student name and an invalid grade of 101 (just above the maximum boundary) in the grade input field, then click the 'Add Student' button. Verify that submission is prevented, an error message is displayed, no entry is added to the student list, and the input values are retained.
