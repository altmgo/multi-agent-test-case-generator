# Add student with valid name and normal grade

Case ID · G-001

Requirements · e2edev\_bench\_49-R-1, e2edev\_bench\_49-R-2, e2edev\_bench\_49-R-5

Enter a valid non-empty student name and a valid grade within the normal range (e.g., 85). Click the 'Add Student' button and verify that the student is added to the student list, the format is correct, and the form fields are reset.
