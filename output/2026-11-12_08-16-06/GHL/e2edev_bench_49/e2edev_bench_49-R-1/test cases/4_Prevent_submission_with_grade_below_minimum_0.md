# Prevent submission with grade below minimum \(\< 0\)

Case ID · G-004

Requirements · e2edev\_bench\_49-R-1, e2edev\_bench\_49-R-2, e2edev\_bench\_49-R-5

Enter a valid student name and an invalid grade below 0 (e.g., -1). Click the 'Add Student' button and verify that submission is blocked, an error message indicating the valid range is displayed, and input values are retained.
