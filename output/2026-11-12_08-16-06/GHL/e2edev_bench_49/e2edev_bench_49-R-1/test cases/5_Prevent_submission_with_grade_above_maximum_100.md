# Prevent submission with grade above maximum \(\> 100\)

Case ID · G-005

Requirements · e2edev\_bench\_49-R-1, e2edev\_bench\_49-R-2, e2edev\_bench\_49-R-5

Enter a valid student name and an invalid grade above 100 (e.g., 101). Click the 'Add Student' button and verify that submission is blocked, an error message indicating the valid range is displayed, and input values are retained.
