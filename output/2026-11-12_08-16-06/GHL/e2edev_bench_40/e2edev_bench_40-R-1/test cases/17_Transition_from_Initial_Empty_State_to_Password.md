# Transition from Initial Empty State to Password Generated State with Valid Criteria

Case ID · G-017

Requirements · e2edev\_bench\_40-R-1, e2edev\_bench\_40-R-3

Verify that when the application is in the initial empty state, entering a valid length (e.g., 10), selecting at least one criteria checkbox, and clicking the generate password button successfully transitions the system to the password generated state and displays the password.
