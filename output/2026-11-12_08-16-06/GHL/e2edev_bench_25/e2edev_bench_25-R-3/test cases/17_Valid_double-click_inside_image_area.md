# Valid double-click inside image area

Case ID · G-017

Requirements · e2edev\_bench\_25-R-1, e2edev\_bench\_25-R-3

User performs a valid double-click within the image container area (data-testid 'image-container'). A heart icon is displayed at the relative click coordinates, disappears after 1 second, and the like count in data-testid 'times' increments by 1.
