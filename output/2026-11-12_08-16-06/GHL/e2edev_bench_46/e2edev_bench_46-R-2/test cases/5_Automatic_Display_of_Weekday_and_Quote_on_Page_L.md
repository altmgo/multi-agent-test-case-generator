# Automatic Display of Weekday and Quote on Page Load

Case ID · G-005

Requirements · e2edev\_bench\_46-R-1, e2edev\_bench\_46-R-2

Verify that upon loading the web page, the application automatically determines the current day of the week using local date settings, displaying the correct day name in the span with data-testid='weekday' and the corresponding quote in the span with data-testid='phrase' inside the container without requiring user interaction.
