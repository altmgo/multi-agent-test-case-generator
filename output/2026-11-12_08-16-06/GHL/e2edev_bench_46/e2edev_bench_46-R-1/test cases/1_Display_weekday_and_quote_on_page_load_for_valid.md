# Display weekday and quote on page load for valid local dates

Case ID · G-001

Requirements · e2edev\_bench\_46-R-1, e2edev\_bench\_46-R-2

Verify that when the web page loads, the application automatically determines the current day of the week from the local date settings and displays the correct day name in the span with data-testid='weekday' and the corresponding quote in the span with data-testid='phrase' for all valid days from Sunday to Saturday.
