Case ID · G-013

Requirements · e2edev\_bench\_09-R-2, e2edev\_bench\_09-R-4

User loads the 'Study Planner' page, enters a task name in the 'Task' input field and a valid date in the 'Deadline' input field, then clicks the 'Add Task' button. The system adds the new task to the task list displaying the correct format and resets the task form fields to empty.
