# Add Transaction with Empty Amount and Valid Description

Case ID · G-043

Requirements · e2edev\_bench\_29-R-3, e2edev\_bench\_29-R-5

Attempt to add a transaction by entering text in 'description-input' but leaving the 'amount-input' field completely blank. Verify that an alert with the message 'Please enter valid description and amount.' is displayed and the transaction is not added.
