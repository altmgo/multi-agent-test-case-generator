# Transaction Validation Failure with Empty Inputs

Case ID · G-039

Requirements · e2edev\_bench\_29-R-2, e2edev\_bench\_29-R-3, e2edev\_bench\_29-R-5

Attempt to add a transaction with empty description or amount input fields, and verify that an alert with the message 'Please enter valid description and amount.' is displayed and no transaction is added.
