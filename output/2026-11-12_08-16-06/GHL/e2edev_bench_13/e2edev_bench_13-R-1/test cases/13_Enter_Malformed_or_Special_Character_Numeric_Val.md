# Enter Malformed or Special Character Numeric Values

Case ID · G-013

Requirements · e2edev\_bench\_13-R-1, e2edev\_bench\_13-R-4

Enter invalid numeric formats or special characters (such as multiple decimals like '12.34.5', negative signs in invalid positions, or alphabetical strings) into the height input field (data-testid='height-input') to test system failure handling and output visibility.
