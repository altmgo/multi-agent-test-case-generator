# Valid Navigation Backward Using Prev Button

Case ID · G-003

Requirements · e2edev\_bench\_52-R-2, e2edev\_bench\_52-R-3, e2edev\_bench\_52-R-4

Verify that clicking the prev-button deactivates the current active progress circle, decreases the progress bar width proportionally, disables the prev-button if the first circle is reached, and enables the next-button.
