# Valid Navigation Forward Using Next Button

Case ID · G-002

Requirements · e2edev\_bench\_52-R-2, e2edev\_bench\_52-R-4, e2edev\_bench\_52-R-5

Verify that clicking the next-button activates the next progress circle, proportionally updates the progress bar width, enables the prev-button, and disables the next-button if the last circle is reached.
