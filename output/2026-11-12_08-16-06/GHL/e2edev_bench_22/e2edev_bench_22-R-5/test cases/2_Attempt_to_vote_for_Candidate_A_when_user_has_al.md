# Attempt to vote for Candidate A when user has already voted

Case ID · G-002

Requirements · e2edev\_bench\_22-R-1, e2edev\_bench\_22-R-5, e2edev\_bench\_22-R-6

Verify that clicking the vote button for Candidate A when 'hasVoted' is set to 'true' triggers an alert with the message 'You've already voted!' and does not change any vote counts.
