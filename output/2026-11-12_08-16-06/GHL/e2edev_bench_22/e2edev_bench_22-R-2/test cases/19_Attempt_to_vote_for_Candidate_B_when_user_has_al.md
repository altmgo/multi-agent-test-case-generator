# Attempt to vote for Candidate B when user has already voted

Case ID · G-019

Requirements · e2edev\_bench\_22-R-2, e2edev\_bench\_22-R-5, e2edev\_bench\_22-R-6

User clicks vote-button-B when 'hasVoted' key is present in localStorage. System displays an alert with the message 'You've already voted!', keeps vote counts unchanged, and leaves the detailed results section hidden.
