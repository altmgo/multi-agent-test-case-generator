# Update Existing Timetable Entry When Time Range Already Exists

Case ID · G-028

Requirements · e2edev\_bench\_18-R-5, e2edev\_bench\_18-R-6, e2edev\_bench\_18-R-8

Test that submitting a timetable entry with a time range that already exists in the timetable updates the cells for the selected days with the new subject name instead of creating a new row, and resets the form.
