# Start Time Later Than End Time Submission

Case ID · G-040

Requirements · e2edev\_bench\_18-R-2, e2edev\_bench\_18-R-3, e2edev\_bench\_18-R-5

Enter a start time that is chronologically later than the end time (e.g., start-time '15:00', end-time '10:00') and click 'Add to Timetable' to check how the system handles illogical time ranges.
