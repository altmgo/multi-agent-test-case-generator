# Identical currencies selected for currency-one and currency-two

Case ID · G-011

Requirements · e2edev\_bench\_60-R-3, e2edev\_bench\_60-R-6

Verify that when both 'currency-one' and 'currency-two' are set to the same currency code, the exchange-rate display updates to show '1 [currency-one] = 1 [currency-two]'.
