# Form Submission with Invalid or Unselected Access Level

Case ID · G-021

Requirements · e2edev\_bench\_30-R-2, e2edev\_bench\_30-R-4

Attempt to submit the form when the 'access' dropdown is set to an invalid state or default unselected value instead of the expected 'Attendee' or 'VIP' options. Verify that validation fails and the badge is not generated.
