# Search with empty or whitespace-only keyword

Case ID · G-017

Requirements · e2edev\_bench\_27-R-1, e2edev\_bench\_27-R-5, e2edev\_bench\_27-R-10

Submit the search form with an empty or whitespace-only input field. A random meal should be automatically fetched and displayed in the single meal container, the result heading should be cleared/empty, and the search input must be cleared.
