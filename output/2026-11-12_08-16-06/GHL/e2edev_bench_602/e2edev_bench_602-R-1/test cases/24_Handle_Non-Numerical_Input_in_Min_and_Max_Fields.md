# Handle Non-Numerical Input in Min and Max Fields

Case ID · G-024

Requirements · e2edev\_bench\_602-R-1, e2edev\_bench\_602-R-2, e2edev\_bench\_602-R-3

Verify that entering non-numerical values into 'Min' and 'Max' fields defaults them to '1' and '100' respectively without altering the default values improperly.
