# Rapid Multiple Clicks on Radio Buttons

Case ID · G-023

Requirements · e2edev\_bench\_59-R-1, e2edev\_bench\_59-R-2

Perform rapid and repeated clicking across multiple answer options ('answer-a', 'answer-b', 'answer-c', 'answer-d') to test mutual exclusivity under stress. Verify that only one option remains selected at any given time and no multiple selections occur.
