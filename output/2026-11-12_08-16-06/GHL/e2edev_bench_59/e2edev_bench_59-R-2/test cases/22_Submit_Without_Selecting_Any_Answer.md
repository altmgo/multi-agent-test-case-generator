# Submit Without Selecting Any Answer

Case ID · G-022

Requirements · e2edev\_bench\_59-R-2, e2edev\_bench\_59-R-4

Attempt to click the submit button (data-testid='submit-button') immediately upon page load without selecting any of the four radio buttons ('answer-a', 'answer-b', 'answer-c', 'answer-d'). Verify that the system does not advance to the next question, keeps the current question displayed, and does not alter the UI state.
