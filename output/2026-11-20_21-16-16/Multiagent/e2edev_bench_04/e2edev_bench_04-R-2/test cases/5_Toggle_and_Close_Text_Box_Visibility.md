# Toggle and Close Text Box Visibility

Case ID · G-005

Requirements · e2edev\_bench\_04-R-2

Verify that clicking the 'Toggle Text Box' button (data-testid='toggle-button') makes the text box (data-testid='text-box') visible by adding the 'show' class, and clicking the 'Close' button (data-testid='close-button') inside the text box hides it by removing the 'show' class.
