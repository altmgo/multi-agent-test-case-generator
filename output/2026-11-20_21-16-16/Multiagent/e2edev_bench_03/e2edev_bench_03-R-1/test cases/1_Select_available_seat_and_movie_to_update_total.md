# Select available seat and movie to update total price and count

Case ID · G-001

Requirements · e2edev\_bench\_03-R-1

Verify that clicking an available seat marks it as selected, updates the selected count element (data-testid='selected-count'), and calculates the total price in (data-testid='total-price') as the number of selected seats multiplied by the selected movie's price from the dropdown (data-testid='movie-select').
