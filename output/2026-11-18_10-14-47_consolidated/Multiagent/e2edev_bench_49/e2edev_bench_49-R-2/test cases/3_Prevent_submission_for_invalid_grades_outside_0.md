# Prevent submission for invalid grades outside 0-100 range

Case ID · G-003

Requirements · e2edev\_bench\_49-R-1, e2edev\_bench\_49-R-2, e2edev\_bench\_49-R-5

Verify that entering a grade below 0 or above 100 blocks form submission, displays an error message indicating the valid range, does not add any item to the student list, and retains the entered values in the input fields.
