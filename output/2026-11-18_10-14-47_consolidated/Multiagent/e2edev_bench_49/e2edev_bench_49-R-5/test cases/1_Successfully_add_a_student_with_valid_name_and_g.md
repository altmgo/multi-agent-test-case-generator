# Successfully add a student with valid name and grade

Case ID · G-001

Requirements · e2edev\_bench\_49-R-1, e2edev\_bench\_49-R-2, e2edev\_bench\_49-R-5

Verify that entering a valid student name and a grade within the inclusive range of 0 to 100, then clicking the 'Add Student' button, successfully adds the entry to the student list in the 'Name: Grade' format, assigns a unique data-id attribute, and resets the form inputs.
