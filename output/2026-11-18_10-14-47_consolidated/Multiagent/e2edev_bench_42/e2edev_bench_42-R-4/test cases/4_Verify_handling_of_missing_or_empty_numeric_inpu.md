# Verify handling of missing or empty numeric input fields

Case ID · G-004

Requirements · e2edev\_bench\_42-R-1, e2edev\_bench\_42-R-4, e2edev\_bench\_42-R-6

Leave various numeric input fields empty while providing a gross salary, then click 'Calculate Salary'. Verify that the system automatically defaults missing numeric values to '0' for calculation purposes and completes the calculations without throwing errors.
