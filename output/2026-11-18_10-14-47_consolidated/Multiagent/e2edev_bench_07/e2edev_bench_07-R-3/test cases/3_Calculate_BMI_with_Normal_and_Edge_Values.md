# Calculate BMI with Normal and Edge Values

Case ID · G-003

Requirements · e2edev\_bench\_07-R-3

Verify that clicking the 'calculate-button' correctly computes the BMI using weight and height inputs, rounds to two decimal places, and displays the result in 'result-display' in the format 'Your BMI is <calculated_value>', supporting normal cases, minimum non-zero values, and maximum reasonable values.
