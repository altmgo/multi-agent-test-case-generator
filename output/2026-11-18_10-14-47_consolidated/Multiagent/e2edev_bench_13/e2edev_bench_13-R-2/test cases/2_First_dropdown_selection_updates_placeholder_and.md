# First dropdown selection updates placeholder and height name

Case ID · G-002

Requirements · e2edev\_bench\_13-R-2

Select a unit from the first dropdown (data-testid='first-option-select') and verify that the input placeholder updates to 'Enter [Selected Unit]...' and the height name section (data-testid='height-name') displays '[Selected Unit]:'. Also test selecting the default 'Select an Option' to ensure placeholder reverts to 'Enter Height...' and the name section is empty.
