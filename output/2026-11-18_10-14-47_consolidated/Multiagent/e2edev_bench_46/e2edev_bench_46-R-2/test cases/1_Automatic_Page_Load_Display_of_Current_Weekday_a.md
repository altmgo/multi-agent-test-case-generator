# Automatic Page Load Display of Current Weekday and Quote

Case ID · G-001

Requirements · e2edev\_bench\_46-R-1, e2edev\_bench\_46-R-2

Verify that upon loading the web page, the application automatically determines the current day of the week from the local computer date and displays the correct weekday name in the span with data-testid='weekday' and the corresponding quote in the span with data-testid='phrase' without any user interaction.
