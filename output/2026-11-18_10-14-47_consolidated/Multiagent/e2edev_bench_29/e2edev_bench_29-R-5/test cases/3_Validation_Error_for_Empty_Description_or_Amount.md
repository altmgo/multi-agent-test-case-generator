# Validation Error for Empty Description or Amount

Case ID · G-003

Requirements · e2edev\_bench\_29-R-2, e2edev\_bench\_29-R-3, e2edev\_bench\_29-R-5

Verify that leaving the 'Description' or 'Amount' input field empty triggers an alert with the message 'Please enter valid description and amount.' and prevents the transaction from being added.
