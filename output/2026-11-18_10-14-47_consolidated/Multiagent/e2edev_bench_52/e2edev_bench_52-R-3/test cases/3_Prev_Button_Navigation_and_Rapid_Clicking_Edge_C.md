# Prev Button Navigation and Rapid Clicking Edge Case

Case ID · G-003

Requirements · e2edev\_bench\_52-R-2, e2edev\_bench\_52-R-3

Verify that clicking the 'Prev' button removes the 'active' class from the current circle, decreases the progress bar width proportionally, disables the 'Prev' button when returning to the first circle, and handles rapid clicks gracefully without going below 0% width or deactivating the first circle.
