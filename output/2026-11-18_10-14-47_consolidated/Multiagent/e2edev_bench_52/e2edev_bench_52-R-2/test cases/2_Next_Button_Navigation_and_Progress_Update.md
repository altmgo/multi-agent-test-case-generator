# Next Button Navigation and Progress Update

Case ID · G-002

Requirements · e2edev\_bench\_52-R-2, e2edev\_bench\_52-R-5

Verify that clicking the 'Next' button marks the next progress circle as active, updates the 'progress-bar' width proportionally using the formula, enables the 'Prev' button, and disables the 'Next' button when the last circle is reached.
