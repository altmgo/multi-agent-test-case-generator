# Switching from Predefined Tip to Custom Tip Conflict

Case ID · G-042

Requirements · e2edev\_bench\_601-R-2, e2edev\_bench\_601-R-3

Select a predefined tip button and subsequently type a custom tip into the 'Custom Tip' input field to check that the predefined button's 'selected' class is successfully removed and the custom tip overrides it correctly.
