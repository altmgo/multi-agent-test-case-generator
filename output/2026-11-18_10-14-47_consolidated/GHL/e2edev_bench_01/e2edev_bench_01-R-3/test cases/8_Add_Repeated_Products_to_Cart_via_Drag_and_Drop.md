# Add Repeated Products to Cart via Drag and Drop and Verify Updated Totals

Case ID · G-008

Requirements · e2edev\_bench\_01-R-1, e2edev\_bench\_01-R-3, e2edev\_bench\_01-R-5

User drags and drops the same product item multiple times into the drop area. The system handles repeated products, updates the quantity and cart details, and correctly recalculates the total price formatted to two decimal places with the currency symbol.
