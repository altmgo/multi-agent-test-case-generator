# Create new note on page load or Add note button click in edit mode

Case ID · G-007

Requirements · e2edev\_bench\_02-R-3

Verify that when the app page loads or the user clicks the "Add note" button (data-testid="add-note-button"), a new note is created that immediately enters edit mode where the textarea (data-testid="note-textarea") is visible and the main content area (data-testid="note-main") remains hidden.
