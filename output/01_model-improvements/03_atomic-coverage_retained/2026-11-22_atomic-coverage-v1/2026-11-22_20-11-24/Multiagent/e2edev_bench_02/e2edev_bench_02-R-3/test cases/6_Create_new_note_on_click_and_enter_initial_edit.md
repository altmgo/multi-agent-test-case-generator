# Create new note on click and enter initial edit mode

Case ID · G-006

Requirements · e2edev\_bench\_02-R-3

When the user clicks the "Add note" button (data-testid="add-note-button") upon app load, a new note is created which immediately enters edit mode where the textarea (data-testid="note-textarea") is visible and the main content area (data-testid="note-main") remains hidden.
