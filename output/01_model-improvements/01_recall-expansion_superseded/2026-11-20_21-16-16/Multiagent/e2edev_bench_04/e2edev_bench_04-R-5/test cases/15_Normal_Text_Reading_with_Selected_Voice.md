# Normal Text Reading with Selected Voice

Case ID · G-015

Requirements · e2edev\_bench\_04-R-5

Verify that when a user enters text into the textarea (data-testid='text-area'), selects a voice from the dropdown (data-testid='voice-select'), opens the text box via the toggle button (data-testid='toggle-button'), and clicks the 'Read Text' button (data-testid='read-button'), the system uses the selected voice to read the entered text aloud.
