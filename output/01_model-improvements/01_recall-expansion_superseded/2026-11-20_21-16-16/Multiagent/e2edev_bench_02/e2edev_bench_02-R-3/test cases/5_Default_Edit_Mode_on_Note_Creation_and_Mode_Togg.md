# Default Edit Mode on Note Creation and Mode Toggle

Case ID · G-005

Requirements · e2edev\_bench\_02-R-3

Verify that when a user creates a new note upon page load, it immediately enters edit mode where the textarea (data-testid='note-textarea') is visible and the main content area (data-testid='note-main') is hidden. Clicking the 'Edit' button (data-testid='edit-note-button') successfully toggles between edit and view modes.
