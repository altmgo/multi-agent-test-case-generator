# Retrieve and display saved notes from localStorage on page load

Case ID · G-010

Requirements · e2edev\_bench\_02-R-5

When the Notes App webpage loads, it retrieves saved notes from localStorage and dynamically creates a div element with the class note containing tools, an "Edit" button (data-testid="edit-note-button"), a "Delete" button (data-testid="delete-note-button"), a main div (data-testid="note-main") with content displayed, and a hidden textarea for notes that have content.
