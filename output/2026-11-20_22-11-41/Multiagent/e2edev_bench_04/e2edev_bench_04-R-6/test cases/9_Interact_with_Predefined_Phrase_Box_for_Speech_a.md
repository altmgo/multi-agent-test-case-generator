# Interact with Predefined Phrase Box for Speech and Highlight

Case ID · G-009

Requirements · e2edev\_bench\_04-R-6

Preconditions: The web application is loaded with dynamically generated predefined phrase boxes containing images and info paragraphs. Steps: Click on one of the predefined phrase boxes. Expected Behavior: The system reads the associated text aloud using the Web Speech API and visually highlights the box by adding the active class for 800 milliseconds.
