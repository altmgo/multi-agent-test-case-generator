# Read Entered Text Aloud Using Selected Voice

Case ID · G-008

Requirements · e2edev\_bench\_04-R-5

Preconditions: The text box is open, a voice is selected in the dropdown (data-testid='voice-select'), and text is entered into the textarea (data-testid='text-area'). Steps: Click the 'Read Text' button (data-testid='read-button'). Expected Behavior: The system reads the entered text aloud using the selected voice via the Web Speech API.
