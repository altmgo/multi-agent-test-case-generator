# Close Text Box Using Close Button

Case ID · G-003

Requirements · e2edev\_bench\_04-R-2

Preconditions: The text box (data-testid="text-box") is currently visible after clicking the toggle button. Steps: Click the 'Close' button (data-testid="close-button") located inside the visible text box. Expected Behavior: The text box is hidden by removing the 'show' class from the text box element in the DOM.
