# Toggle Text Box Visibility via Button

Case ID · G-001

Requirements · e2edev\_bench\_04-R-1

Preconditions: The Speech Text Reader application is loaded and the text box (data-testid="text-box") is initially hidden. Steps: Click the "Toggle Text Box" button (data-testid="toggle-button"). Expected Behavior: The text box appears with the 'show' class applied. Clicking the button again hides the text box by removing the 'show' class, reflecting the last user action accurately.
