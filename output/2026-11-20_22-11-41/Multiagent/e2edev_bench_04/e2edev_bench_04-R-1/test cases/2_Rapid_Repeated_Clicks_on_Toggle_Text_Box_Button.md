# Rapid Repeated Clicks on Toggle Text Box Button

Case ID · G-002

Requirements · e2edev\_bench\_04-R-1

Preconditions: The text box (data-testid="text-box") is initially hidden. Steps: Rapidly click the 'Toggle Text Box' button (data-testid="toggle-button") multiple times in quick succession. Expected Behavior: The final visibility state of the text box reliably reflects the last user action without inconsistency, correctly adding or removing the 'show' class.
