# Page Load Population and Multiple Voice Selections

Case ID · G-007

Requirements · e2edev\_bench\_04-R-4

Preconditions: The page is fully loaded and available voices are present. Steps: Check the dropdown upon page load, then select a first voice, and subsequently change the selection to a second voice. Expected Behavior: The dropdown is populated upon full page load, and the system handles multiple selections ensuring the last selected voice becomes the active voice.
