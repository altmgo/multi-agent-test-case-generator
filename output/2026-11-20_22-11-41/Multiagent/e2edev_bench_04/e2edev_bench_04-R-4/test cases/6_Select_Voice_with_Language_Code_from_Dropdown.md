# Select Voice with Language Code from Dropdown

Case ID · G-006

Requirements · e2edev\_bench\_04-R-4

Preconditions: The voice dropdown (data-testid='voice-select') is populated with available voices. Steps: Select a voice option containing a specific language code such as 'CN' or 'US'. Expected Behavior: The system accurately sets the selected voice containing the language code as the active voice for speech synthesis.
