# Verify initial edit mode and mode toggling functionality

Case ID · G-005

Requirements · e2edev\_bench\_02-R-3

Verify that upon clicking the 'Add note' button, the note immediately enters edit mode where the textarea (data-testid='note-textarea') is visible and the main content area (data-testid='note-main') is hidden. Clicking the 'Edit' button (data-testid='edit-note-button') toggles between view and edit modes, displaying formatted content and hiding the textarea in view mode, and vice versa in edit mode.
