# Real-time Markdown rendering for valid syntax

Case ID · G-003

Requirements · e2edev\_bench\_02-R-2

Verify that typing valid Markdown syntax (e.g., # Heading, **bold**, _italic_, [link](...)) in the textarea (data-testid="note-textarea") dynamically renders the corresponding HTML formatting in real-time within the main display area (data-testid="note-main"), and the changes are immediately saved to local storage.
