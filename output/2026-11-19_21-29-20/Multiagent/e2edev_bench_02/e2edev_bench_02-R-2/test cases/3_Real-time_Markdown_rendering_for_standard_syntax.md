# Real-time Markdown rendering for standard syntax

Case ID · G-003

Requirements · e2edev\_bench\_02-R-2

Verify that when the user types standard Markdown syntax such as headers, bold text, italic text, and links into the note textarea (data-testid="note-textarea"), the content is dynamically and correctly rendered in real-time within the main display area (data-testid="note-main"), and changes are immediately reflected in local storage.
