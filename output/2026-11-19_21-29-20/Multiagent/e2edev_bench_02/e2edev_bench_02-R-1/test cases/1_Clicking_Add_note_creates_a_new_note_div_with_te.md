# Clicking Add note creates a new note div with textarea

Case ID · G-001

Requirements · e2edev\_bench\_02-R-1

Verify that when the user clicks the Add note button (id="add", class="add", data-testid="add-note-button"), a new note is created and appended to the document body as a div element with the class "note" containing a visible, empty textarea (data-testid="note-textarea").
